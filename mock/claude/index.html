静的 HTML / JS はテーマ切替のみ

画面モック索引

docs/(specification.md / architecture.md / persona.md)の Must 機能を基準に作成した静的モックです。 フォームやボタンは動作しません(見た目と情報設計の確認用)。 ヘッダー右上のボタンでライト / ダークを切り替えられます(既定は OS 設定に追随。選択はページを跨いで保持されます)。

初回リリース(Must)

ランディング /

未ログインのトップ。ナビはログイン状態で出し分ける。

 会員登録 /signup

ユーザー名・メール・登録地域・パスワード。バリデーションエラーの表示例つき。

 ログイン /login

保護ルートからのリダイレクト着地点の案内つき。

 予報とコーデ(通常) /forecast

週間予報 + 7日分の一括入力。未保存の変更と保存トーストを表示。

 予報とコーデ(前回の予報) /forecast

last-known-good(status: 'stale')と、未保存離脱の警告ダイアログ。

 予報とコーデ(取得失敗) /forecast

502 でも入力・保存を継続。409(同時編集の競合)のトーストつき。

 モバイルのドロワーナビ /forecast

768px 以下でのメニュー展開。ウィンドウを狭めて確認する。

 コーデ履歴 /history

直近30件を日付降順で。気温 null・地域切替中の記録も含む。

 コーデ履歴(空状態) /history

記録が0件のとき。入力画面への導線を出す。

初回リリース対象外(Should)

アカウント設定 /settings

表示名・登録地域・パスワードの変更。アカウント削除は位置のみ確保。

モックで表現した仕様

  • 1画面で1週間分を一括入力(persona.md §3 / spec §3)。900px 以下では1日1カードに切り替わる
  • 地域切替セレクタと、切替中に保存した記録が履歴で地域名つきに見えること(決定事項 #29 / #30)
  • 予報の鮮度と出どころ: 発表時刻・「地域の代表地点の予報」表記・fresh / stale のバッジ(spec §5)
  • 「出典: 気象庁ホームページ」を全ページのフッターで常時表示(法的要件)
  • 502 でも入力・保存が継続できること(snapshotStatus: 'unavailable' = 気温なし表示)
  • 未保存の変更を保存バーで明示し、離脱時にダイアログで警告する(spec §5)
  • 409(同時編集の競合)を再読み込み導線つきのトーストで通知(決定事項 #32)
  • 履歴の最小版: 日付・3項目・保存気温・地域名のみ(spec §2.3)
  • 入力制約: コーデ各項目は50文字、3項目すべて空にすると記録が削除される(spec §4)
