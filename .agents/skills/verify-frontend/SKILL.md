# フロントエンド検証

`apps/web` の実装後に、Playwright MCP と Chrome DevTools MCP で実際の画面を検証する。**Vitest では拾えない実ブラウザ上の問題**(レンダリング崩れ、コンソールエラー、パフォーマンス、アクセシビリティ)を対象とする。

## 前提

1. `pnpm docker` で PostgreSQL が起動していること
2. `pnpm dev` で web(:3000)と api(:3001)が起動していること
   - 起動していなければ**先にユーザーに起動を依頼する**。勝手に長時間プロセスを立ち上げない
3. 検証用アカウント: `admin@example.com` / `password123` / 地域 `130000`

## 手順

### 1. 対象を絞る

`git status` / `git diff --stat` で変更されたルートを特定し、**変更に関係する画面だけ**を検証する。全画面を毎回見ない。

### 2. 動作確認(Playwright MCP)

対象画面を開き、実装した操作を一通り実行する。フォームがあれば**正常系と異常系の両方**を通す。

確認すること:

- 意図した表示・遷移になっているか
- バリデーションエラーが**日本語で**表示されるか
- レスポンシブ(モバイル幅でドロワーナビに切り替わるか)

### 3. コンソール・ネットワーク(Chrome DevTools MCP)

- `list_console_messages --types error` — **エラーはゼロが基準**
- `list_network_requests` — 意図しない 4xx / 5xx、重複リクエストがないか

### 4. パフォーマンス(Chrome DevTools MCP)

`performance_start_trace`(`reload: true`, `autoStop: true`)→ `performance_stop_trace` で Core Web Vitals を取得する。閾値を超えた項目は `performance_analyze_insight` で内訳を見る。

### 5. アクセシビリティ(Chrome DevTools MCP)

`lighthouse_audit`(`mode: "navigation"`)でスコアと失敗した監査項目を取得する。加えて、Lighthouse が検出できない以下を手動で確認する:

- キーボードのみで主要操作が完結するか(Tab / Enter / Esc)
- フォーカスリングが見えるか
- フォームの入力欄に対応するラベルがあるか

## 判定基準(暫定)

実際の画面を見て調整してよい。調整したらこのファイルを更新する。

| 項目 | 基準 |
| --- | --- |
| コンソールエラー | 0 件 |
| 意図しない 4xx / 5xx | 0 件 |
| LCP | 2.5 秒以下 |
| CLS | 0.1 以下 |
| INP | 200ms 以下 |
| Lighthouse Accessibility | 90 以上 |

## プロジェクト固有の必須チェック

該当画面を触った場合は必ず確認する(要件由来のため、スコアとは別に必須):

- **「出典: 気象庁ホームページ」が常時表示**されている(法的要件)
- 未認証で `/forecast` 等の保護ルートを開くと `/login` へリダイレクトされる
- **予報の取得に失敗(502)しても、コーデの入力・保存が継続できる**
- 日付は `YYYY年M月D日`、気温は `℃` 表示
- 地域切替セレクタが登録地域を書き換えない

## 問題が見つかったら

1. **`modern-web-guidance` スキルで該当する解決パターンを検索してから**直す(レガシーな実装で塞がない)
2. **確定スタックを勝手に置き換えない**(`.agents/rules/stack.md`)。shadcn/ui・Tailwind v4・RHF の内側で解決する
3. 修正後、該当箇所だけ再検証する

## スコープ外

- **E2E テストコードを書かない**(`.agents/rules/stack.md` の非スコープ)。この検証は使い捨てで、Playwright のテストファイルをリポジトリに追加しない
- ロジックの単体テストは Vitest の担当。ここでやり直さない

## 報告

最後に簡潔にまとめる。長文のレポートは作らない。

```
検証: /forecast(デスクトップ / モバイル)
- 動作: OK(フォームの異常系含む)
- コンソール: エラー 0
- Core Web Vitals: LCP 1.2s / CLS 0.02 / INP 90ms
- Lighthouse a11y: 96
- 必須チェック: 出典表記 OK / 502 時の保存 OK
- 修正: セレクタに aria-label を追加(a11y 88 → 96)
```
