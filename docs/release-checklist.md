# Haregi(ハレギ)公開前チェックリスト

デプロイ先・CI・E2E をいずれもスコープ外としているため([architecture.md 決定事項 #14 / #23](./architecture.md)、[specification.md §6](./specification.md))、**リリースの成立条件を人手のチェックリストとして固定する**。CI を導入しない方針であっても、確認すべき項目そのものは減らない。

- 作成日: 2026-08-03(設計レビューの指摘 #8 を受けて新設)
- 適用: 限定公開(クローズドα版)と一般公開でゲートが異なる。下記の §1 は両方、§2 は一般公開のみ

---

## 1. 限定公開(クローズドα版)の前に

### インフラ・セキュリティ

- [ ] HTTPS で配信されている
- [ ] セッション Cookie の属性が正しい(`Secure` / `HttpOnly` / `SameSite`)。**web → api のプロキシ越しに `Set-Cookie` が転送されることを実機で確認**する
- [ ] `BETTER_AUTH_URL` / `WEB_ORIGIN` / `trustedOrigins` が本番のオリジンを指している
- [ ] プロキシ経由でも Host / Origin の検証が意図どおり効いている(リバースプロキシがヘッダを書き換える場合の挙動を確認)
- [ ] `BETTER_AUTH_SECRET` が本番用に生成された値で、リポジトリに含まれていない
- [ ] `GET /api/doc` と `/api/openapi.json` を本番で公開するか決めて設定した(**開発用ドキュメントであり、既定は非公開**。公開する場合はその判断を記録する)

### データベース

- [ ] マイグレーションの適用手順が文書化されている(`pnpm db:migrate` を誰がいつ実行するか)
- [ ] **ロールバック手順**がある(適用したマイグレーションを戻せるか、戻せないなら前方修正のみと明記する)
- [ ] バックアップが設定され、**復元を1回試して成功している**(取得できているだけでは確認にならない)
- [ ] DB 接続プールがプロセス終了時に正しく閉じられる(SIGTERM ハンドリング)

### 運用

- [ ] readiness / health check エンドポイントがある(DB 接続を含めて判定する)
- [ ] **本番でシードのテストユーザー(`admin@example.com`)が作られない**仕組みになっている(`pnpm db:seed` を本番で実行しない、または環境変数でガードする)
- [ ] `LOG_LEVEL` が本番向け(`info`)に設定されている
- [ ] 気象庁の地域マスタ検証(`apps/api/scripts/validate-areas.ts`)を実行し、全58区分が通る

### 動作確認(手動・再現可能な手順として記録する)

- [ ] signup → login → forecast 取得 → コーデ保存 → **再読み込みして保存内容が残っている** の一連が通る
- [ ] 地域を切り替えて保存したコーデに、**切替後の地域の気温**が記録されている(決定事項 #29 / #30)
- [ ] 過去日のコーデを文言だけ編集しても、**保存済みの気温が消えない**(決定事項 #31)
- [ ] 気象庁への到達を止めた状態でも、コーデの入力・保存が継続できる(気温は null)
- [ ] 同じ週を2つのタブで開いて両方から保存すると、古い方が 409 になる(決定事項 #32)
- [ ] 未ログインで `/forecast` にアクセスすると `/login` へリダイレクトされる
- [ ] 「出典: 気象庁ホームページ」が常時表示されている
- [ ] モバイル実機で1週間分の入力を通しで行い、**タップ数・スクロール量・キーボード表示時の操作性**が許容範囲であることを確認する(1画面に7日×3項目を置く構造の実測。[persona.md](./persona.md) の「入力が面倒だと続かない」に対する受入条件)

### 品質ゲート

- [ ] `pnpm lint` / `pnpm format` / `pnpm typecheck` / `pnpm test` がすべて通る

## 2. 一般公開(不特定多数への公開)の前に

限定公開の全項目に加えて、以下を満たすまで公開しない([specification.md §6](./specification.md))。

- [ ] **パスワードリセット**が動作する(メールプロバイダ契約済み・実際に受信して再設定できることを確認)
- [ ] **アカウント削除**が動作する(DB のカスケード削除に加え、**ストレージのオブジェクトも消えること**を確認)
- [ ] 上記2つがない期間の運用(DB 直接操作による救済)を終了した
- [ ] 写真機能を提供する場合: オブジェクトキーの所有権検証・presign の発行上限・孤児オブジェクトの掃除が動作している([architecture.md §8](./architecture.md))
- [ ] 利用規約・プライバシーポリシーの要否を判断した(個人データを預かるため)
- [ ] 障害時の連絡先・問い合わせ窓口がある

---

## 3. 定期実行

- [ ] **月次**: 気象庁の地域マスタ検証スクリプトを実行し、区分・アメダス地点・区域コードの変更を検知する(気象庁側の変更は予告なく起こりうる。CI がない以上、実行しなければ検知されない)
